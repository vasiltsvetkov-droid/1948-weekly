## Classification Levels

| Level | Description |
|---|---|
| Excellent | Top-tier performance |
| Above Average | Above the group mean |
| Average | Group mean range |
| Weak | Below average, monitor |

> **Inverse** = lower value is better (e.g. time, asymmetry, valgus angle).
